# Avatar model notice

`man.glb` and `woman.glb` are Avatar SDK MetaPerson sample assets used for local
product evaluation. They are not original BONYAN artwork and must not be shipped
or redistributed in a production release until the appropriate Avatar SDK usage
and distribution rights have been confirmed.

Production builds can replace the local samples without code changes by setting
`EXPO_PUBLIC_AVATAR_MEN_MODEL_URL` and `EXPO_PUBLIC_AVATAR_WOMEN_MODEL_URL` to
licensed CDN or avatar-provider URLs.

- Model samples: https://avatarsdk.com/avatars/
- Provider terms: https://avatarsdk.com/eula/
